# Ride-Sharing-Application
NOTE: I have only uploaded parts of the system which I worked on, so the ability to amend/cancel a booking and pay for a amendment/cancellation are not included.

A group university project graded 87%. Me and my team worked together using agile methodologies across two sprints to develop a ride sharing application, allowing users to make or join existing bookings for taxi-style rides to different UK airports.

This was my first time using Agile and working with git (via GitLab), and showed me the importance of incremental development and version control.

Key roles I took in this project:
•	Designed and built the main underlying system, ensuring it would be scalable for each sprint; and implemented two user stories: the ability for the user to make a booking with algorithms to find matching services, and the ability to enter their payment details for payment – all with exception handling to ensure inputs were valid. Used GitHub Copilot for AI-assisted coding, reviewing and testing its suggestions.
•	Used Java and git to allow for incremental development across sprints, and tracking of our implemented features. Wrote JUnit tests and reviewed team members’ code. This allowed us to work cohesively with each other, improving our throughput and working efficiently towards our tight deadlines.

Outcome: a usable application graded 87%, the project expanded my skills in software development, and gave me experience in agile and test-driven development. As team leader, I developed skills in giving and receiving feedback, resource management, and supporting and mentoring people.
